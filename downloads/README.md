# SnapSort Android debug download

Download [SnapSort-download.zip](https://github.com/jheelsonare/Snapsort/raw/refs/heads/main/downloads/SnapSort-download.zip), then extract it. Install `SnapSort-debug.apk` on an Android 11 or newer device. This is a debug build, not a Play Store release. Android may ask you to allow installation from the browser or file manager you use.

The ZIP is approximately 35 MB; the extracted APK is approximately 120 MB. The ZIP contains exactly one APK. `SHA256SUMS` lists both the ZIP and extracted APK hashes.

SnapSort processes OCR locally and requests gallery access. Images are moved to Android trash only after review and Android confirmation. Trash may not immediately free storage. See [../README.md](../README.md) for use/build instructions and [../VALIDATION.md](../VALIDATION.md) for exact test results and known coverage limits.
